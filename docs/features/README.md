# Feature pages

These are the specs agents build from. They are copies of the pages in Yanni's
"ZOH launch plan" document, which stays the master: when a decision changes there, these files
are regenerated from it. Agents read them but don't edit them; anything a page should say
differently goes in the PR description (see `docs/runbook.md`).

| File | What it is |
| --- | --- |
| `coach-voice.md` | How ZOH talks, pushes and handles slips. Applies to every feature; wins any disagreement. |
| `template.md` | The shape of every feature page, how agents use it, ideas beyond scope, and how coach mistakes are fixed and kept fixed. |
| `04-onboarding.md` | Feature 4: onboarding by text (plus what features 3 and 8 need for today). |

Pages for features 5 to 14 are added as they're written.
